MAHAKAL SKETCH-MAKING EXACT FINAL PROJECT

This project does exactly this flow:
1. White pencil sketch making
2. Blue neon sketch making
3. At the end, exact same Mahakal image appears in Turtle output

Run:
python main.py

No extra dependency needed for running.
The paths are already generated inside mahakal_paths.json.

To make faster:
UPDATE_EVERY_POINTS = 35
PATH_DELAY = 0.001

To make slower:
UPDATE_EVERY_POINTS = 10
PATH_DELAY = 0.006
